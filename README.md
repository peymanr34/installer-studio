# Installer Studio

Combine multiple installers for silent installation.

## Features

- Silent switch detection for Inno Setup, Nullsoft, WiX Burn and MSI installers
- Multiple compilers support including [Inno Setup](https://jrsoftware.org/isinfo.php) and [NSIS](https://nsis.sourceforge.io/Download)
- Supports x86, x64 and ARM64 specific installers
- Supports Appx and MSIX app packages
